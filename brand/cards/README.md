## Карточка поста: что можно менять

Текст задаётся в адресе файла (параметры после `?`):

- `rub` - готовый пример: `demo` (Демо недели), `before` (Было - стало), `tip` (Совет для бизнеса);
- `rubric` - текст в бирюзовой плашке;
- `h` - заголовок (до ~60 знаков, иначе не влезет);
- `sub` - подзаголовок;
- `demo` - какое демо в телефоне: `shinomontazh`, `barbershop`, `salon`, `flowers`;
- `layout` - `one` (один телефон и пометка со стрелкой) или `two` (слева «сейчас» - карточка без сайта, справа демо);
- `pen`, `pen2` - рукописные пометки.

Пример: `card.html?rub=demo&demo=flowers&h=Букет можно собрать прямо на сайте`

## Как получить картинку

Просить Claude: «сделай карточку: рубрика ..., заголовок ..., демо ...». Claude делает снимок через Edge без окна:

```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new --user-data-dir="<временная папка>/edge-prof" --disable-gpu --hide-scrollbars --allow-file-access-from-files --force-prefers-reduced-motion --virtual-time-budget=15000 --window-size=1080,1350 --screenshot="<куда>.png" "file:///C:/Users/Пользователь/CloudeCode/Бренд-дизайн/brand/cards/card.html?rub=demo"
```

Важно:
- без `--user-data-dir` Edge молча не обновляет снимок;
- без `--force-prefers-reduced-motion` в демо салона не успевают появиться фото;
- русский текст в адресе кодировать (`urllib.parse.quote`).

## Видео из bloom.html

Кадры снимаются тем же Edge с параметром `t` (`bloom.html?t=0.5`): 100 кадров от t=0.08 до t=1. Затем ffmpeg склеивает их в MP4 (H.264, 20 кадров в секунду, последний кадр держится 2,5 секунды, итого 7,5 секунды, около 220 КБ). Последний кадр сохранён как картинка-запас. Если нужно поменять текст в видео, он правится прямо в `bloom.html`.
