# Шрифты

Шрифты лежат на самом сайте, чтобы браузер посетителя не обращался к серверам Google (IP посетителя не уходит третьей стороне).
Скачаны с Google Fonts (fonts.gstatic.com) 8 октября 2026. Наборы символов: кириллица, латиница, расширенная латиница (в ней знак ₽).
Подключение на страницах: `<link href="../../fonts/fonts.css" rel="stylesheet">`. Браузер скачивает только шрифты, которые есть на открытой странице.

Все шрифты распространяются по лицензии SIL Open Font License 1.1: её разрешено использовать, встраивать в сайты и распространять вместе с ними. Текст лицензии: https://openfontlicense.org/open-font-license-official-text/
